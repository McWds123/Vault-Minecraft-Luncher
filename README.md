# Vault Minecraft Launcher

### Custom startup script
In version 1.1.0, you can use an exe as the startup script to launch Minecraft.

### Others
Other functions are waiting for future updates.

### Supported system
Only supports Windows systems.
Only supports 64-bit.

# Vault Minecraft Launcher 2

## VML 2.1.0.0
重构了大部分代码，添加了启动版本和版本列表的功能。
对比 Vault Minecraft Launcher 优化了性能，使用了高级动画，使用 HTML 制作窗口。

  ### 如何启动版本？
  1. 在主目录下找到 Minecraft 文件夹
  2. 在 `Minecraft/VML/Script/` 下添加版本文件夹，例如 `1.21.1`
  3. 在 `Minecraft/VML/Script/1.21.1/` 下创建 `Run.bat` 启动脚本
  4. 打开 `VML.exe`，选择版本后启动游戏即可
## VML 2.2.0.0
添加了下载版本 使用官方源
对比2.1.0.0 优化了HTML的样式
简化了文件结构
  ### 如何启动版本?
  1. 在主目录下找到 `Minecraft/VML/你下载的版本` 文件夹
  3. 在 `Minecraft/VML/Script/你下载的版本/` 下创建 `Run.bat` 启动脚本
  4. 打开 `VML.exe`，选择版本后启动游戏即可
